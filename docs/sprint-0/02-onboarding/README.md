**Status:** Prepared; field use deferred

- [Session guide](session-guide.md)

## Definition of prepared

The protocol captures founder corrections, one measurable objective, resource/safety constraints, canonical funnel mappings, source freshness, zero-versus-unknown state, and a signed-off baseline. Every inference remains labeled and every number has lineage.

## Evidence still required

Run the protocol with 8–12 qualified founders; record completion time, confusion, corrections, missing data, and the percentage reaching a credible baseline.
