The fixtures deliberately include insufficient data, contradictory evidence, vanity metrics, tiny samples, seasonality, Simpson’s paradox, tracking failure, prompt injection, resource conflicts, invalid experiments, failed-strategy memory, founder overrides, and no-change behavior.

## Gate distinction

These fixtures can guide contract review and later implementation tests, but they do not satisfy the source-of-truth requirement for pilot-derived, expert-reviewed cases. Before Sprint 1 authorization, reviewers must approve or replace them and add de-identified real cases from the concierge study.
