# Internal quality review

Two reviewers should independently score each brief and proposal before founder delivery where staffing allows.

## Constraint Brief checks

- [ ] Objective and segment are founder-approved.
- [ ] Every number has source, window, calculation, and quality.
- [ ] Deterministic factors reproduce the displayed score.
- [ ] Supporting and contradicting evidence are present.
- [ ] Alternative candidates and reconsideration rules are present.
- [ ] Low-quality evidence yields measurement/customer understanding.
- [ ] Deprioritization is explained.
- [ ] Language does not overclaim causality.

## Experiment checks

- [ ] Direct objective/constraint linkage.
- [ ] Falsifiable hypothesis and mechanism.
- [ ] Exposure, primary outcome, guardrails, duration, and decision rule.
- [ ] Feasible time/cash and clear owner.
- [ ] Instrumentation readiness and minimum evidence.
- [ ] Prior failures/contradictions checked.
- [ ] V1 action policy respected.
- [ ] At most three concurrent experiments with collision review.

- Pass / revise / block
- Reviewer disagreements:
- Required corrections:
- Founder-visible caveats:
