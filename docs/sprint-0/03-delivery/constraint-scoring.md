# Constraint scoring worksheet

Use deterministic scoring before narrative synthesis:

`constraint_score = impact × reach × tractability × evidence_quality × urgency`

Each factor is in `[0,1]`. The formula ranks candidates; it does not manufacture certainty.

| Candidate | Impact | Reach | Tractability | Evidence quality | Urgency | Score | Evidence for | Evidence against |
|---|---:|---:|---:|---:|---:|---:|---|---|
|  |  |  |  |  |  |  |  |  |

## Factor anchors

| Factor | 0.0 | 0.5 | 1.0 |
|---|---|---|---|
| Impact | No plausible objective effect | Moderate downstream sensitivity | Direct, material objective leverage |
| Reach | Negligible affected population | Meaningful subset | Most relevant opportunities/users |
| Tractability | No feasible intervention | Feasible with notable constraints | Feasible within current time/cash |
| Evidence quality | Missing/invalid | Partial or mixed evidence | Fresh, mapped, adequate evidence |
| Urgency | Can safely defer | Review this cycle | Delay materially harms goal/learning |

## Selection rules

1. If evidence quality is below the agreed threshold, select measurement/instrumentation or customer understanding instead of a funnel stage.
2. The lowest conversion percentage is not automatically the constraint.
3. Record the top alternative and what evidence would make it primary.
4. Record why tempting unrelated activities are deprioritized.
5. Founder overrides create a decision record; do not alter factor values to hide disagreement.
