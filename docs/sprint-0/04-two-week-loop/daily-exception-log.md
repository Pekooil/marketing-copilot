- Date/timezone:

- Goal progress state:
- Active constraint/version:

- Missing/stale/conflicted metric:
- Material anomaly:

## Decision

- No strategic change / request evidence / prepare asset / request founder decision / recommend stop / revise next plan
- Evidence references:
- Rationale:
- Founder time requested:
- Due/expiry:

## Founder response

- Approve / edit / reject / defer / mark external work complete
- Reason:
- Decision reference:
- Effect on experiment/plan:

## No-change statement

When no threshold is crossed, use: **“No strategic change; continue collecting data until {{checkpoint}}.”** Do not add filler recommendations.
